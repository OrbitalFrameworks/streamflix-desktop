# Streamflix Desktop 1.4.0 — Consolidated Windows UX release

Release scope: accumulated post-1.3.9 native Windows UX and playback changes.

## User-visible changes

- Player embedded directly in the Streamflix main window, with explicit pop-out option and fullscreen controls.
- Contextual Mi lista actions, searchable scope chips and filtered saved titles.
- Editorial movie/series hero, title-derived placeholders when artwork is missing, responsive Home/Detail layouts, and keyboard-focus feedback.
- An actionable first-run Home when the catalog is not populated, linking directly to TMDb settings, Movies and Live TV.
- Compact Continue Watching empty state with direct exploration instead of an oversized inert placeholder.
- Reduced-motion preferences apply to scrolling as well as navigation and hover transitions.

## Validation required before release

- Java 17 compilation and deterministic Linux/Windows test suites on the release candidate SHA.
- Native Windows GUI E2E at 1480×900, 1280×800 and 1024×768, including Search, Detail, Settings and embedded player. Inspect screenshot provenance AND rendered images.
- Windows `release.ps1` packages EXE/MSI/ZIP and runs its packaged self-test. Verify SHA256 sidecars and version match `VERSION`.
- Tag `v1.4.0` only after the PR is merged and CI green on the main SHA. Confirm the published release assets exist.

## Limits

- External streaming providers/artwork depend on configuration, connectivity and third-party changes; synthetic test playback does not certify every provider.
- Existing installations are not modified until the user installs the new EXE/MSI (or uses the supported portable updater).
- Chromecast and accounts remain out of scope.
