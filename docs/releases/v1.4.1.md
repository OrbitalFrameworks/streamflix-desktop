# Streamflix Desktop 1.4.1 — Player, focus and image quality fixes

- Replaces bright yellow top-navigation focus rectangles with a restrained slate underline, preserving keyboard location feedback.
- Keeps TMDb high-resolution catalog backdrops and uses cached bicubic enlargement when necessary. Image sharpness is constrained by the original provider asset; Data Saver only limits stream bitrate.
- Adds a reverse **Volver a integrar en Streamflix** control to pop-out player windows. It reopens the same stream in the MainFrame from the saved playback position.
- Fixes player transfers reusing invalidated mpv request IDs and avoids blocking the Swing UI thread while the replacement stream opens.
- Fullscreen pop-out now targets the entire physical screen (including taskbar bounds), restoring previous window and Pin states on exit.
- Adds regression tests for artwork URL preservation, reverse docking and Windows native fullscreen display bounds.

Verification before publication: Java17 deterministic tests, GitHub Windows/Linux CI on the branch and merged main, native E2E pop-out/dock/fullscreen and packaged Windows self-test. Runtime production video providers remain independently variable.
