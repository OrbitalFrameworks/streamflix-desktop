# Streamflix Desktop 1.4.2 — Catalog viewport correction

The Movies, Series, Search, Live TV and Mi lista grid now tracks the actual scroll viewport width, even when item preferred dimensions would otherwise expand it.

This prevents the rightmost card from being cropped or causing invisible horizontal overflow when the scrollbar itself is disabled. The same viewport-tracking behavior was already used on Home; the catalog now follows it too.

Native Windows GUI E2E validates the catalog body width and the horizontal boundaries of populated search cards. The preceding v1.4.1 player redocking, full-monitor fullscreen, focus and image-quality improvements are included unchanged.
