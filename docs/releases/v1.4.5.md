# Streamflix Desktop 1.4.5 — Home scroll tear mitigation

## Fixed

- A second real Windows recording confirmed that horizontal bands and mismatched parts of the Home hero persisted in v1.4.4 when scrolling vertically.
- Removed the custom 16-ms scroll-easing timer for the **full Home viewport**. Native Swing wheel scrolling now updates the viewport once per wheel event, rather than scheduling a stream of full-page redraws for each wheel action.
- Retained the 1.4.4 non-blitting viewport mode, the automatically rotating featured titles (12-second interval), the Previous/Next buttons and the existing horizontal shelf controls.

## Validation and limitations

- Java 17 deterministic test suites and graphical Linux E2E passed across 1480x900, 1280x800 and 1024x768.
- New E2E checks require native Home wheel input, an immediate change of scroll position and no pending vertical smooth-scroll timer.
- The original tearing was observed in Windows video recordings, but its disappearance must be checked in the same Windows display environment. This change addresses the identified high-frequency repaint path, not a proven GPU-driver-specific root cause.
