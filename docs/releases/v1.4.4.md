# Streamflix Desktop 1.4.4 — Rotating Home highlights and scroll repaint correction

## Changed

- The Home banner now cycles through up to ten unique available film and series highlights every 12 seconds. The initial title varies between app launches rather than always selecting the highest-rated series.
- Previous and Next controls enable manual exploration. Every slide retains normal Play, More information and Mi lista actions.
- The banner keeps a fixed height when the selected item changes. Switching highlights does not rebuild the Home shelves or move Continue Watching.

## Fixed

- The Home viewport uses full repaint instead of pixel blitting during vertical scrolling to address stale horizontal strips and flickering in the layered banner observed in a Windows screen recording.

## Validation and limitations

- Java 17 deterministic tests cover featured selection, deduplication, cycling and stable dimensions.
- Multi-resolution GUI E2E under a virtual Linux display covers the banner, non-blitting viewport, unchanged Home geometry and rest of the application flows.
- The original Windows recording's visual artifact has not been independently retested on the user's Windows graphics/driver setup; this release is intended to make that direct verification possible.
